# שחר פתרונות — אתר תדמית

אתר B2B לשירותי סורסינג, רכש ויבוא מסין.

**סטטוס: תשתית ותוכן מוכנים. העיצוב ממתין לרפרנס ויזואלי מהלקוח.**

## הרצה

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## סטאק

Next.js 16 (App Router) · TypeScript · Tailwind v4 · RTL מלא (`lang="he" dir="rtl"`)

## אילוץ עיצובי מחייב

**הלקוח עיוור צבעים** — אינו מבחין בין אדום לשחור בקווים דקים.
לכן שום מידע באתר לא מועבר בגוון בלבד: כל מצב מסומן גם בטקסט,
בסימן, במסגרת או בניגודיות. אין אדום/ירוק כמדדי מצב.
**אי אפשר להסתמך עליו לאישור פלטה** — צריך גורם מאשר מטעמו.

## קליטת לידים

הלקוח ביקש לעבוד מול Google Sheets ולא מול CRM.
`/api/lead` שולח את הפנייה ל-webhook שמוגדר במשתנה הסביבה `LEAD_WEBHOOK_URL`
(למשל Google Apps Script שכותב שורה לגיליון).
כל עוד המשתנה לא מוגדר — הטופס עובד, והפנייה נרשמת ללוג בלבד.

```bash
# .env.local
LEAD_WEBHOOK_URL=https://script.google.com/macros/s/.../exec
```
