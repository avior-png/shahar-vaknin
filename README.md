# שחר פתרונות — אתר תדמית

אתר B2B לשירותי סורסינג, רכש ויבוא מסין.

**סטטוס: כל המבנה בנוי, סביב הוויזואלים שטרם יוצרו.**

## הקונספט — "מבפנים"

הלקוח של שחר עומד תמיד בחוץ: מחוץ לשער המפעל, מחוץ לשפה, מחוץ למכולה
ברגע שהיא נסגרת. שחר נמצא בפנים. האתר הוא כניסה הדרגתית פנימה — סין
כהה בראש העמוד — ויציאה בצד השני, ישראל בהירה בתחתיתו.

מכאן נגזרות שלוש החלטות מבניות:

- **הציר.** מנוף גשר של מפעל (`01-crane`) חוצה שלושה אזורים לגובה, והתוכן
  זורם לצידו. הפריסה שומרת לו עמודה קבועה — ראה `.spine-zone` ו-`.spine-safe`.
- **הריתמוס.** כהה → שבירה כתומה → כהה → בהיר. הוא לא החלטה גרפית אלא המסע עצמו.
- **הדגלים כסוגריים.** סין פותחת את עמוד הבית, ישראל סוגרת אותו. מסכת הדגל
  הישראלי היא בעיקר לבן ולכן עובדת רק על הרקע הבהיר — ראה `FlagWord`.

## אילוץ עיצובי

**הלקוח עיוור צבעים** ואינו מבחין בין אדום לשחור בקווים דקים. הוא אמנם
לא קהל היעד של האתר, אבל המערכת בנויה כך ששום מידע לא עובר בגוון בלבד:
כל מצב מסומן גם בטקסט, בסימן או בניגודיות. **אי אפשר להסתמך עליו לאישור
פלטה** — צריך גורם מאשר מטעמו.

## קליטת לידים

הלקוח ביקש לעבוד מול Google Sheets ולא מול CRM.
`/api/lead` שולח את הפנייה ל-webhook שמוגדר במשתנה הסביבה `LEAD_WEBHOOK_URL`
(למשל Google Apps Script שכותב שורה לגיליון).
כל עוד המשתנה לא מוגדר — הטופס עובד, והפנייה נרשמת ללוג בלבד.

```bash
# .env.local
LEAD_WEBHOOK_URL=https://script.google.com/macros/s/.../exec
```
