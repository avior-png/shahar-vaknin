# Design Studio — עורך ויזואלי חי

כלי פיתוח לסגירת פינישים ויזואליים בעכבר, בלי סבב פרומפטים.

## הפעלה

```bash
npm run dev
```
ואז פותחים בדפדפן `http://localhost:3000/?edit`

שלושה תנאים מצטברים לטעינה: **פיתוח בלבד**, **דגל `?edit`**, ו-**import
דינמי**. לכן המודול כולו נושר מבנדל הפרודקשן — נבדק, אפס תווים ממנו
ב-`.next/static`.

## שני עולמות

| | פיתוח | פרודקשן |
| --- | --- | --- |
| מקור הסגנון | הקוד + פתקים חיים | קוד אחד נקי |
| `!important` | כן — כדי לנצח את ה-CSS הבסיסי | **לא** |
| מערכת העורך | רצה | **לא עולה בכלל** |
| קובץ הפתקים | נטען | **לא קיים בתוצר** |

הקוד המקורי **לא משתנה לעולם**. האפייה יוצרת קובץ נפרד.

## מה יש בפאנל

**בחירה** — hover מסמן, קליק בוחר. קליק על `<b>` בתוך פסקה בוחר את
הפסקה; קליק על אות בכותרת מפוצלת בוחר את הכותרת.

**עץ מבנה** — לקריאה בלבד, לבחירת אלמנטים שקשה ללחוץ עליהם (רקעים,
מיכלים, שכבות). בלי גרירה ובלי שינוי סדר.

**בקרות** — טקסט, טיפוגרפיה (גודל, משקל, ריווח, גובה שורה, יישור,
פונט מ-Google Fonts), צבע בבורר HSV עם שקיפות, מרווחים ב-4 כיוונים,
מידות, פינות, מסגרת, צללים, שקיפות, מיזוג, סיבוב, ורקע מלא. כל בקרה
מספרית היא **סליידר + תיבת מספר מסונכרנים**. יש גם שדה **מתקדם**
חופשי בפורמט `prop: value` לכל דבר חריג.

**שלושה מסכים** — דסקטופ / טאבלט / מובייל, כל אחד בנפרד בלי ירושה.
כפתור **״החל על שאר המסכים״** מעתיק הכל בלחיצה.

**הסתרה** — נפרדת לכל מסך, עם רשימת מוסתרים והחזרה בלחיצה.

**רשת ביטחון** — Undo/Redo (`⌘Z` / `⌘⇧Z`), איפוס אלמנט, איפוס הכל,
ושמירה אוטומטית ל-localStorage בכל שינוי.

## פרסום ואפייה

1. **״פרסם״** שולח את הסט המלא ל-`/api/studio`, שכותב ל-`studio.overrides.json`.
   הפרסום **ממזג ולא דורס** — העורך טוען את מה שכבר פורסם בעלייה, כך
   שעריכות מאזורים אחרים לא הולכות לאיבוד.
2. **`npm run build`** מריץ אוטומטית את `scripts/bake-studio.mjs`, שמייצר
   את `src/app/studio-baked.css` — CSS נקי, בלי `!important`, כל מסך
   ב-media query שלו. הקובץ מיובא ב-`layout.tsx` **אחרי** `globals.css`
   ולכן מנצח בקסקדה בזכות הסדר בלבד.

## סטיות מהמפרט — מודעות ומנומקות

**טקסט לא נאפה אוטומטית.** כל הקופי של האתר יושב בקובץ אחד
(`src/content/site.ts`), ולכן עדיף להעביר עריכת נוסח לשם ידנית מאשר
לשכתב קבצי מקור אוטומטית — שזה בדיוק מה שהמפרט מגדיר כשביר. סקריפט
האפייה **מדפיס את כל עריכות הטקסט הממתינות** בסוף הריצה.

**הסתרה מלאה מיוצרת כ-`display:none` ולא כמחיקה פיזית.** מחיקת JSX
אוטומטית מהתוצר אינה בטוחה. המשקל שנחסך זניח, והתנהגות הדף זהה.
